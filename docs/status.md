# ROV HiL and SiL current status

## Implemented

This repository defines the independent VM or dedicated-hardware simulation boundary, with ROS 2/Gazebo and NATS-facing integration planned around `ros2_ws/`, `configs/`, and `scenarios/`.

## Automated-test verification

The documentation currency audit is implemented in `tests/test_documentation.py`. Scenario and ROS test evidence must be recorded separately.

## Bench-tested and Production-validated

Simulation success is not physical ROV or production validation. No physical validation is claimed here without explicit evidence.

## Planned or unverified

Complete Gazebo models, bridge execution, repeatable scenarios, and hardware-in-the-loop validation remain subject to the evidence recorded in the relevant test documents.
