# Performance and simulation time

Measure real-time factor, update rates, bridge latency, message age, CPU use, memory use, and dropped or delayed messages under the documented workload.

Record whether a result uses real-time or accelerated simulation, and whether the NATS and ROS 2 paths remain within the scenario tolerances. A visually smooth simulation is not sufficient evidence of timing correctness.

Repeat performance measurements after changes to the model, sensors, bridge, or scenario complexity.

Relevant course stages: Day 4 for sensor rates, Day 6 for bridge latency, and Day 7 for evidence.
